TextCatch 화면캡쳐 확장 프로그램 설치 (PC 크롬 / 엣지)
=====================================================

http 접속(외부 IP, enfish.duckdns.org)에서는 브라우저 보안 정책 때문에
화면 공유 방식 캡쳐가 막혀 있어 이 확장 프로그램으로 캡쳐합니다.
설치 후에는 공유 확인 창 없이 바로 캡쳐됩니다.

1. 이 폴더(textcatch_capture)를 PC 의 지워지지 않을 위치에 압축 해제
   (예: D:\tools\textcatch_capture)  ※ 폴더를 지우면 확장 프로그램도 동작하지 않음
2. 크롬 주소창에 chrome://extensions  (엣지는 edge://extensions) 입력
3. 오른쪽 위(엣지는 왼쪽 아래) "개발자 모드" 켜기
4. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 1번 폴더 선택
5. 텍스트 캐치 수신 메시지 조회 화면을 새로고침 → 📷 버튼 사용

접속 주소(IP/도메인)가 바뀌면 manifest.json 의
content_scripts.matches 에 주소를 추가한 뒤 확장 프로그램 화면에서 ↻(새로고침) 하세요.
(포트 번호는 적지 않아도 모든 포트에 적용됩니다)
